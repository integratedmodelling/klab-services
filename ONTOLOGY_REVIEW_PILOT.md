# Try the ontology review pilot

Use existing colleague accounts when convenient. No new account is needed to finish preparing
this pilot. An operator supplies the review URL and checks access before inviting participants.

Editors can:

1. Open the supplied Resources review URL and sign in. Choose **Prepare review draft**, enter
   the proposal details, and review the generated starting document. It includes available
   `@review` annotations and project `BOOTSTRAP.md` material; it does not imply approval.
2. Save the candidate, then **Start cycle from selected proposal**. Open a reviewer round,
   a community round, or both. Share the cycle/iteration URL with the intended colleagues.
3. Keep the editable candidate beside feedback. Filter by contributor or contribution proposal,
   integrate changes into a fresh saved revision, and start another cycle when ready.
4. Close iterations or the cycle when appropriate. Closure freezes that history; it does not
   accept or publish the ontology. Another cycle can be opened later.

Reviewers and community participants sign in through the same URL. Check the displayed
proposal revision and iteration, then save a private draft or submit feedback and an optional
alternative proposal. Submitted feedback is visible to participants admitted to that iteration;
editors see all submitted feedback. Drafts stay with their author. Submitted material cannot be
rewritten; corrections are new contributions. A conflict requires refresh and an explicit retry.

The project Git digest links to the persistent protected cycle. It contains no contribution text,
drafts or contributor identities, and the link grants no access. Editors can check its local commit
receipt or retry a deferred archive from a closed cycle. Email delivery is disabled in this pilot;
check the stage UI for new contributions.

The automated multi-user results use simulated identities. Testing real colleague login,
permissions and revocation is a separate step. Operators use the
[setup and acceptance worksheet](notes/ontology-review-colleague-checks.md).
