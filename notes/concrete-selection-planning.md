# Concrete collective selection planning

The bounded Tier-1 capability resolves a concrete qualified collective subject or agent by
resolving its native collective once, executing normal CLASSIFICATION operations for the
requested predicates' lexical families, and returning a source-backed filtered view. Native
discovery removes all direct requested predicates, including identities and roles. It retains
the substantial itself (including an authored subclass), semantic clauses and observer wrapper;
normal scope, generation, discovery support and production admission still apply.

The Reasoner supplies a typed synthetic strategy after authored strategies, following the
existing collective-reduction capability pattern. There is no new general-purpose ATTRIBUTE or
SELECT language implementation and no essential imod strategy-file change. Tier-0 models of the
full requested observable remain first. Enumeration order from OWL or HTTP cannot change the
plan: predicates are ordered by their Concept URN, and every predicate retains its corresponding
explicit lexical root. Competing predicates in one lexical family are rejected rather than
choosing a parent or multiplying dependencies. Concrete lexical roots use normal `any` self
classification; abstract roots use normal family classification.

The portable `CollectiveSelectionBinding` is admission data, not evidence that discovery or
classification succeeded. Resolver lowering emits the native root(s) first and one normal
CLASSIFICATION UPDATE root per family. Each operation has an execution-time completed-native
reference, not a second copy of the native discovery subtree. Runtime validates and executes this
finite plan under the same root transaction and establishes completion and final membership.

At root level the capability produces a result view. As a model dependency it lowers to a typed
deferred virtual input on that dependency's REFERENCE actuator; the enclosing model retains its
own root result and the dependency retains its model-local alias. The portable nested selection
plan must be executed and replaced by a checked view inside the same native transaction before
eager consumer compilation. It does not turn a virtual view into a persisted observation or
promote a child's result descriptor to the enclosing Dataflow. Existing full-model paths for
qualified dependencies remain available.

Collective events, relationships, compound or quantified requests and occurrence forms are
outside this capability; their existing resolution routes remain available. All four normal
classifiable predicate kinds—attribute, identity, realm and role—use the same family contract.

Applying roles from different lexical families preserves conjunction in OWL: each has its own
`hasRole some Role` restriction. Combining all roles into one `hasRole some (A or B)` would only
require one attribution and would disagree with the requested conjunctive view. Alternatives
inside one authored role remain alternatives; this change does not flatten a role's own meaning
or permit competing role values in one lexical family. Trait and role accessors remain distinct.

Distinct native cohorts can be expressed by ontology-authored substantial subclasses. This
feature does not implement individual-identity cohort partitioning or authority-hosting changes.
The runtime result is a virtual selection over original members, not a fabricated qualified
instantiation; successful empty selection must rest on completed native discovery, while missing
required knowledge remains failure. No-op and transaction/rollback behavior are Runtime concerns,
not assertions derived from the presence of this plan descriptor.

Native spatial discovery can resolve a representable missing footprint and retain existing
completed contributors. Temporal exclusion is not implemented by the current Time extent: the
Resolver checks whether a computed complement accounts for the missing proportion and otherwise
conservatively rediscovers the full requested support, retaining the completed prefix. This is
not a claim that temporal discovery runs only over missing intervals. Neither case permits an
incomplete discovery to certify exhaustive empty selection.

Nested selected plans complete their normal classifier-expanded inputs before dispatching native
discovery or a selected family model. Both continuations follow the Resolver's model-native
context rule: a substantial producer owns its model inputs, while quality and UPDATE models
retain their bearer context. Frozen ordinary classifier obligations carry the context captured
when that model was resolved, rather than the root compiler's context. Their typed witness pins
the assigned ID, provisional transient identity, logical URN, Concept semantics, portable geometry
and scope. Older plans without the witness are accepted only for durable contexts; provisional
contexts are never recovered by matching their semantic URN alone.

A selected input remains a private live input until its parent attempt finishes. Other lexical
families may enrich the same members before a characterizer reads that input again. A private
registry keyed by the exact root transaction and Java view object refreshes its receipt through
normal checked sealing and the earliest durable member guard. Membership, source IDs, support
and member geometries must remain unchanged. Internal continuation clones reattach only ports
known to that coordinator with matching transient node identity, alias and receipt. Transported
copies acquire no such capability and retain strict replay checks. The registry is released on
root commit or rollback; no serialized flag or public submission path grants it.

The existing automatic **abstract quality-value substitution and family-expansion** continuation
still imposes an already observed singular native context at Resolver admission. This bound
currently applies to both `CURRENT_MEMBER` and `DIRECT_QUALITY_DOMAIN`; it is an implementation
limit of that older continuation, not a requirement of CLASSIFICATION semantics. This is distinct from a direct
collective CLASSIFICATION operation dependency, which requires support geometry and can precede
native instantiation without a singular context. Concrete collective selection does not turn the
former substitution route into a new general classifier interface. A full Resolver regression checks its specific rejection before discovery, while a
supported observed-context quality dependency checks real ordinary classifier expansion before
a nested concrete selection completes. The latter test isolates native completion at an explicit
fixture boundary; it is not evidence for the unsupported fresh-context combination.
