## How to read these records

These are historical snapshots, not current task authorization or proof that checks
pass today. Statements that a file is outside the repository describe its original
location. Checkout paths, branch/PR states and test results describe the recorded
checkpoint; reverify before acting. Paths inside each record retain their original
workspace or repository context, not this directory. The next-PR plan ends mid-sentence
in the supplied original; no missing content has been invented.
