# Production candidate publication review checkpoint

Base: e65a01d7f3c9cb268e9963ee139cde86ab96752f. Isolated branch: codex/candidate-publication-slice. This implementation is not installed; live e65 service ownership remains with the integration owner.

The production load/update entry points now keep the approved authoritative prepared-bean gate before scheduling. A rejected bean batch touches no OWL or release state. Successful preparation freezes a complete worldview and submits it to the single background candidate worker. Source-order, source hashes, captured dependency bytes and configuration revision accompany each submission. A candidate owns its compiler actor, OWL manager, HermiT, index, caches, parser, scope and dependency directory. The accepted generation changes only after complete logical validation; failures, unresolved dependencies and stale candidates preserve the prior readable actor.

Semantic API calls, internal resolve operations, documentation and namespace exports use one accepted actor lease for the whole operation. Contextual callbacks rebind semantics and aggregate service discovery to that actor. Builder terminal calls and multi-call search sessions keep their originating actor alive. Concurrency regressions cover shutdown before late search registration and close before a blocked terminal builder resumes. Raw root compiler/cache/OWL access fails explicitly. DTO and syntax inputs are copied, returned semantic DTOs are owned copies, and only match's declared output map may be written back.

The existing LanguageAdapter, ObservationPlanAdapter and WorldviewValidationScope now live in core.services so Resources and private candidates share the same implementation. Candidate parsing owns a fresh injector/parser, validation scope and adapter; it does not call live Resources to parse arbitrary definitions. The catalog binds an OWL import alias and requested document URL to exact captured bytes. Optional `<alias>.sha256` entries pin historical numbered files whose versionIRI differs from their directory version. No remote fallback or implicit substitution of bundled OWL for a numbered URL is allowed.
