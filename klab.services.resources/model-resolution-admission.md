# Model resolution admission prerequisite — diagnosis in progress

This separate prerequisite is authorized only for a reproduced **non-scientific
admission or transport defect** and its regression tests. No root cause is yet
established and no product fix is currently included. Original frozen fixture,
synthetic compatibility variant/model bytes, fixed numerical oracle, scientific
algorithms, shared worldviews, dependencies and deployments stay unchanged.

## Preserved blocker

The earlier controlled full-service attempt6 passed readiness and confirmed two
context/two observation submission receipts. Region result retrieval/grid checking
passed; elevation result notification decoding raised `JobFailedError`. Numerical

## What the baseline establishes

Preserved service logs contain region model-query entries but no elevation model
query entry. Native resolver code can emit FAILED before model discovery if no
observation strategy survives. That observation suggests an early admission/focus
hypothesis; it does **not** prove it.

Two native offline diagnostic cases pass on integration base5785c1baa:

1. The native parsed `dependent.direct` strategy rejects an unfocused concrete
   quality and admits the same quality with a native context observation.
2. A native scope-token reconstruction plus observation DTO serialization roundtrip
   preserves that focus and strategy admission on a reconstructed service scope.

These use a synthetic diagnostic vocabulary, real parser/adapter/pattern selection,
and native scope/value implementations with mocked external services. They do not
execute a model, submit a Job, disable a guard or establish full-worldview admission.
The first test placement failed compilation because it referenced a package-private
scope admission helper from another package. The test moved to the matching package;
the helper's product visibility was not widened and the failed log is retained.

Three additional native OWL diagnostic cases pass: a concrete declaration can have
an effectively abstract dependent expression when its identity requirements remain
unfulfilled; an explicit eligible bearer discharges the synthetic requirement;
a plain bearer supplies no invented identity evidence. These exercise the existing
rules, not permission to change them. Two more cases verify that a typed unresolved
snapshot envelope retains focus without registration and that transport plus focus
does not silently concretize an abstract request. All seven tests pass locally.

An offline read of the unchanged compatibility worldview confirms that Elevation
is declared concrete, has parent `physical:Height of earth:Location`, and Height
requires an Areal or Volumetric identity. Native adaptation preserves the concrete
Elevation declaration. This alone cannot establish what a served query should
return or whether contextual inference correctly discharges that requirement.

The first service probe captured an ABSTRACT flag on served Elevation, then stopped
before inference because the private harness did not allow the strategy POST. Its
failure is preserved, not treated as an endpoint rejection. Zero scientific Jobs
and observation registrations occurred. Context/session release, empty-context
listing, publisher socket absence and HTTP closure passed. All14 recorded JVM
identities were independently absent afterward, with no matching visible windows.

The second inference-only probe, after correcting the exact private endpoint
allowlist, completed successfully. It returned **no Elevation strategies** both
unfocused and with the uncommitted Region focus. No observation registrations or
scientific Jobs occurred. All context/session/list/socket/HTTP cleanup passed;
all14 recorded JVM identities were independently absent. A PID reused by an
unrelated process was preserved; all3,905 attested backend input hashes matched.

No current result reproduces a proven non-scientific defect or justifies a speculative
product change. A bounded control comparison is in progress: the original Elevation
query, concrete Aspect quality, and a read-only explicitly qualified Elevation query.
Each is tested unfocused and with a snapshot focus (maximum six inference requests).
An alternative query is **not** a substitute for the fixed acceptance question or
permission to change fixture/model/oracle bytes. The probe uses the actual declared
`/api/v1/observationStrategies` contract, served semantic metadata and uncommitted
focus snapshots. Its setup allows one disposable context; its scientific submit
budget is zero and there are no observe/submit call sites. This is not a Job retry.
This prerequisite changes no product code;75Reasoner and10Resolver main Java source
files match the unchanged diagnostic backend. Test infrastructure
uses the separately verified draft117 cleanup, not a deployment or merge.

PR heads b63c3bd13 and ac2ab0e88 passed the general build, both offline diagnostic
jobs and Jenkins. The expanded seven-case suite still requires final-head CI. Passing tests
are software diagnostics, not scientific or notification acceptance.

## Gates before any fix or merge

- Establish a reproducible failing non-scientific admission/transport boundary;
  preserve failed, passing and UNKNOWN evidence rather than weakening semantics.
- Only then add the smallest authorized correction and before/after regression.
- Review source and packaging, relevant broader tests and final-head CI separately
  from genuine numerical/notification acceptance; never replay earlier submissions.
- If resolution would require scientific algorithm/worldview/oracle changes, stop
  and obtain a new explicit scope decision instead of extending this authorization.
