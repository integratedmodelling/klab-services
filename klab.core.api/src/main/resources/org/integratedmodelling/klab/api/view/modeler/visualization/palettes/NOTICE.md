The 256-sample viridis, magma, inferno and plasma RGB tables are from
[BIDS/matplotlib colormaps](https://github.com/BIDS/colormap/blob/master/colormaps.py),
by Nathaniel J. Smith, Stefan van der Walt and, for viridis, Eric Firing.
They are released under the [CC0 public-domain dedication](https://creativecommons.org/publicdomain/zero/1.0/).
The original floating-point samples are retained; rendering rounds channels to eight bits.
