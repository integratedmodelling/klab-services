## Scientific, lifecycle and security assessment

Java's single-use column-order input array and the separate hand-authored north-first
table/coordinate/ordered-offset oracle are deliberately distinct. Byte hashes are
checked before/after reader validation. Masked cells, genuine zero and finite
precision remain separate. The fixture does not pretend NaN nodata is a valid
nonfinite measurement or infer timestamps/revisions from metadata.

Fixed loopback ports must be free; generated identity and state are private before
secrets are written. No production login or untrusted-origin forwarding is added.
Four bounded component imports are journalled with UNKNOWN before each mutation,
then checked through their actual Jobs; ambiguous outcomes are never replayed.
Each invocation requires fresh owned state. Context/session releases are independent
and preserve primary errors; all owned processes close in finally. Existing Java
identities are checked without stopping any Modeler service or unrelated console.
No registered Git worktree is created. One component build sandbox is retained as
evidence; it is not an active feature branch or an external-repository modification.
