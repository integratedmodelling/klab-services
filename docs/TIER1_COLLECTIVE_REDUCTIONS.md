# Bounded Tier-1 collective reductions

Observational containment is a permission to request observations, not spatial enclosure,
parthood, inherency or a coverage guarantee. A count/presence request does not need a
Tree-contained-in-Region axiom: its requested geometry binds contextual discovery.

This implementation slice adds a built-in rank-one route for count/presence of a concrete
Subject or Agent. The existing Resolver tries successful Tier-0 strategies first. Only
outstanding work may resolve the corresponding collective, execute an instantiator or reuse
an existing completed cohort, enumerate actual members, and reduce them to one scalar.
`count of` is QUANTIFICATION; `presence of` is VERIFICATION with boolean storage.
The semantic operand comes from operator decomposition, never text/URN stripping.

## Supported boundary

The request must carry one explicitly non-distributed whole-support geometry: size one,
nonempty, nongeneric dimensions with no distributed dimension. Portable geometry uppercase
regular dimensions may still be distributed even when cardinality is one; a whole extent
must be represented explicitly as non-distributed. A pure geometry `1` without support
coordinates is not a discovery binding. This route does not broadcast a whole-region count
into grid/time cells. Unsupported requests remain unresolved through this route; independent
Tier-0 models remain eligible under their ordinary contracts.

Only unannotated unary count/presence is supported. Explicit units, currencies, numeric
ranges, nested operators, abstract operands and explicit observed-as requests do not acquire
this derived route. Their independent/direct strategies are unchanged. This is a bounded
implementation choice, not a new rule that these observations are semantically illegal.
Observer-specific substantial discovery outputs are rejected by this derived route: current
output-refinement receipts cover qualities/processes and cannot certify an absolute collective
from a differently qualified substantial output. Absolute discovery under an implicit selected
observer remains supported, with its actual selection recorded.
General unit/geometry mediation, Height redistribution and perspective-specific derivation
remain staged work.

## Completion and provenance

Planning is not completion. At execution the Runtime re-queries the collective and requires
one actually successful INSTANTIATION activity proving complete requested support. A pending,
failed, cancelled, unknown or partial discovery does not establish zero or false. A successful
empty discovery yields count zero/presence false. Actual geometry-clipped member identities
(including canonical transaction-local provisional identities) are enumerated and deduplicated; producer childrenCount is never the reduction operand.

The portable request binding fixes context identity/support, selected actual observer and
reasoner identity/revision. New collective execution records semantic revision and observer
selection. Missing/legacy completion evidence cannot certify this derived route. Replanning
is required after semantic revision or selected-observer changes. This does not globally
invalidate legacy observations or ordinary query/reuse paths.

Member semantic eligibility uses the existing ObserverResolution contract on the singular
operand. A creator's actual observer instance is not a member compatibility constraint.
Absolute members remain eligible for implicit requests; a compatible specific Agent class
can be reused even when its actual observer differs. An incompatible member cannot silently
be treated as nonexistent and counted as zero; the whole-support reduction remains unresolved.
Actual provenance is preserved. This first slice does not compose competing partial
perspective discoveries or infer a complete membership snapshot from them.

## Executable model admission

Named producer plans retain the accepted reasoner identity/revision captured before the
resolution attempt. Dataflow compilation rejects revision drift rather than relabeling an
old plan with a new revision. The exact saved namespace version/hash and a stable executable projection hash are captured
in the same admission call before semantic matching, retained on the attempt graph and
transported to the actuator. Runtime compares both original hashes before rechecking source/
executable admission in the actual invocation context, and checks again afterward. A source
or computation change at the same ontology revision still requires replanning. The projection
covers outputs, dependencies, computation, geometry and authored annotations, excluding routing,
logs and ranking diagnostics. This is a snapshot witness, not a new compiler-origin signature.
Namespace-free ad-hoc producers do not acquire fictitious saved-namespace hashes.
 Missing named source or missing/stale
receipt fails closed and requires replanning. Namespace-free ad-hoc producers remain a
separate contract. This guard supports conditional dependency validation; it does not waive
native bearer restrictions or abstractness/identity obligations.

## Verification boundary

Focused tests exercise production OWL unary construction, strategy generation, Resolver,
Dataflow transport, collective completion/query/member enumeration, Groovy scalar compilation
and scalar storage with controlled catalog/graph/service I/O. They are not a live-stack or
cotechino end-to-end acceptance result. No consequence-engine inference is added.


## Whole-support transport witness and execution proof

The reduction binding carries an explicit portable whole-support geometry derived from the original
non-distributed dimensions. This matters because a local physical `Scale` may encode its single
whole interval as `T0`, losing the flag retained in an authored portable `t0`. The reduction plan
preserves the witness in its output geometry and requested support. Runtime verifies the actual
submitted target is scalar and non-distributed, and compares its promoted support with that witness.
A raw portable `T0` request remains ineligible; ordinary geometry encoding is unchanged.
For an already promoted local Scale, its actual extent distribution is authoritative: promotion of
both `T0(...){ttype=PHYSICAL}` and `t0(...){ttype=PHYSICAL}` currently produces the same
non-distributed physical Time. Historical portable regularity cannot be recovered from that Scale;
this witness records the actual input geometry at capture, not an unavailable earlier wire history.
An actual distributed GRID Scale remains ineligible.

`CollectiveReductionPipelineTest` executes production strategy generation, ResolutionCompiler,
DataflowCompiler, production Actuator-interface transport, CompiledDataflow, its child
ContextualizerExecutor, successful instantiation transaction, completion query, actual member
enumeration, and real scalar Groovy/storage in one root invocation. It covers portable and initial
Scale requests, empty count/presence, nonempty presence/count, failed discovery, and distributed
request rejection. Catalog/source validation responses, scheduler dispatch, graph persistence, and
individual member-submission acknowledgements are controlled disposable I/O boundaries. This is
not live-service acceptance or a test of arbitrary instantiator models or individual acknowledgement
strategies. Separate tests retain observer/revision failures, partial/unknown completion and Tier-0
precedence.
