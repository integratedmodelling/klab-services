# Conditional source model contexts — bounded implementation candidate

Observational containment is an authored permission to request a member-native observable in a container observation. It is not spatial enclosure, parthood, coverage, member discovery, sampling, redistribution, or a statement that members exist.

A model whose native output is Stream-borne may depend on Region-borne fields only when one actual contextual type proves every dependency bearer clause and an authored Stream-contained-in-Region contract permits the output request there. Both native bearer declarations remain unchanged. Source validation records required named context alternatives, or a typed pending conjunction of declared-container and dependent-semantic references when the complete required context is anonymous. Pending source conjunctions must be satisfiable, preserve each dependency's full boolean clauses, and prove no actual context or observation existence. Explicit abstractness, generic and unresolved identity errors remain errors. Executable admission always recomputes the complete actual-context proof; a pending descriptor never authorizes execution. Source validation records required context alternatives; it does not assert universal executability. If TerrestrialRegion alone proves an input, the obligation is TerrestrialRegion, not all Region.

Executable catalog/selection validation binds the actual observed context semantic URN into SemanticValidationRequest and its matching receipt, using the existing source snapshot and knowledge revision checks. Missing, unrelated, stale or unproved contexts fail closed. A source author cannot discharge this obligation by writing unchecked model metadata. Runtime must revalidate producing models in the actual execution scope before using these conditional models; this patch requires the coordinated common runtime guard before integration.

Source validation supports a single quality or process output, including unitful qualities, and records semantic context obligations only. It does not validate a runtime sampling or redistribution operation. Executable conditional admission remains limited to a single semantically proven Ratio output with explicit unity: nearest canonical `odo:unit="1"` metadata and no declared output unit. Missing or conflicting metadata is unknown, not unitless. Ratio ancestry and canonical unity are both necessary. Ratio ancestry alone is insufficient because ratios can be dimensionful; unity metadata alone cannot make an Angle or Length a Ratio. Every declared output unit, including rad and degree_angle, remains rejected on the conditional route until general semantic unit validation is implemented. This restriction does not validate the original StreambedGradient formula or its scientific interpretation.

Any supported executable route must retain the actual query support. No Tier-1 discovery is required for eligible direct Tier-0 models; successful Tier-0 models retain precedence. Generic, identity, explicit abstractness, native process identity and ordinary bearer checks still apply.

Semantic source/context admission is necessary but does not implement a container-to-native-member execution bridge. In particular, an actual Stream-parented StreambedGradient invocation still executes in Stream scope and must reject regional Elevation/Slope inputs there. Do not replace that native scope with a root Region to make the guard pass. A future typed bridge must bind the regional invocation and support separately from native per-member computation/results. These source tests do not prove that the original StreambedGradient model executes, and neither general indirect-inherency redistribution nor live acceptance is claimed.

## Validation consequences of substantial `within`

Source context obligations apply to single quality/process outputs independently of
canonical units. The output keeps its native bearer; the candidate container must
admit that output through the authored containment contract and prove every input
bearer clause. The executable validator still recomputes admission in the actual
scope and retains the narrower unitless Ratio gate. An accepted source obligation
is not a bridge, a unit-conversion proof, or a completed member observation.

Request admission uses positive boolean native-bearer expressions to find named
candidate witnesses. Each
candidate must independently prove the entire bearer expression and all separate
clauses, and equal or specialize a declared member endpoint. Union alternatives
are not intersected, separate member identities are not combined, and complements
or nested property fillers do not manufacture witness candidates. With a loaded
reasoner, unsatisfiable candidates are rejected. No anonymous witness is invented.
Anonymous required invocation contexts retain the existing typed pending source
conjunction; native-bearer witnesses do not become invocation-context candidates.

Multiple-output conditional models remain unsupported. Supporting them requires a
joint output/native-support contract and per-output execution admission rather than
reusing a dependency proof for a contained secondary output. General quality and
process execution also needs semantic unit handling and a typed sampling or native
member bridge. These are remaining implementation boundaries, not reasons to reject
a single-output semantic source obligation.
