# Native root commit and cold numeric recovery

This verification follows the preserved [independent product milestone](CLASSIFIER_CARTESIAN_RECOVERY.md).
The automatic scope remains INIT, one deferred quality dependency, direct positive ATTRIBUTE
factors and one certified leaf producer. No new membership, correlation, aggregation, composition
or persistent invalidation policy is introduced.

## Actual ordinary submission boundary

`SelectedModelClassifierSubmissionTest.ordinaryCartesianSubmissionCommitsNativeRootAndColdReopensNumericStorage`
installs embedded KnowledgeGraphNeo4j and real StorageManagerImpl **before Runtime.submit**.
It seeds the owning cohort and existing observations through native transaction store/link/close.
Native source capture, readset validation, semantic updates, new observation/shard storage,
prerequisite links and root close execute production code against real embedded Cypher transactions.
The context/provenance/dataflow anchors use production initialization queries. The bridge adapts
embedded values to driver values and allocates IDs; it avoids unrelated Bolt startup conflicts.
Catalogue/source-parser transport and component registration remain explicit fixture boundaries.
OWL/HermiT, semantic construction/redeclaration, validation, strategy planning, scheduler, classifier
execution, concrete computation and the final graph-reading contextualizer use production paths.

The captured native Region cohort contains three actual IDs: the current Region and two observed
members. The current Region is explicitly classified Wheat/Warm, matching one other member;
the third is Maize/Cool. Each classifier processes all three members. Independent Crop and Season
closures still yield the complete2x2 product. Four distinct monetary child observations produce
1,2,3,4 in USD@2020, and one final contextualizer explicitly computes10. Generated qualities retain
their declared native Region bearer and independent identity; graph child/dependency edges do not
change inherency or containment. This is an authored valuation calculation, not an implicit sum.

Real numeric storage uses explicit temporary directories and EXPLICIT_ACTION. After native root
success, the test flushes and closes storage and creates both a fresh graph/cache and a fresh storage
manager. With no live transaction, normal family access restores the same four child IDs and
bindings, then reads parent10 and child1,2,3,4 from persisted numeric files using native HAS_DATA
shard descriptors. It also compares the recovered Region count with six native HAS_CHILD edges.
No completed result is copied or re-persisted as a substitute for the submission's own root commit.

## Persistence defects exposed and repaired

Fresh attribution copies contain primitive child counters. Later transaction-owned child links
previously incremented only the original object, while the classification guard projected that
delta from both original and stale replacement. Each exact owned increment now reaches the
current replacement too, with matching rollback. Successive attribution copies inherit the current
count; foreign counter or metadata changes still invalidate the guarded read.

Persisted semantic updates previously skipped that counter entirely. An additive typed transaction
overload now atomically applies the root's exact nonnegative owned child delta with the semantic
comparison/update. It preserves unrelated payload and the existing two-argument zero-delta behavior.
Unsupported graph implementations fail on nonzero deltas. Newly stored attribution replacements
already contain their full counter and do not take this existing-observation increment path.
Native readsets remain validated on the same root transaction before any root writes.

Both graph store paths previously omitted geometry for a single shard, while native storage
reconstruction requires the shard's own support. All nonnull shard geometries now use the existing
HAS_GEOMETRY persistence path. The standalone writer has a separate cold descriptor regression;
the ordinary-submission test exercises the transactional writer and numeric rehydration. No parent
geometry is inferred, since invocation support may differ. Historical records already missing
geometry are not migrated by this change.

## Verification limits

This is cold graph/storage reconstruction inside one test JVM with a live embedded database,
not a full service/process restart or a write-after-restart buffer-ID continuity proof. The numeric
fixture is temporal; the harness does not provide the spatial extension. Existing cohort hull
lookup may report the missing spatial.bbox procedure and take its preexisting no-hull fallback;
this does not verify spatial index behavior. No mock spatial procedure or geometry certificate is
introduced. Fixture parser transport retains the actual compound/optional syntax needed on reload;
subtype and native eligibility results are not mocked. The worked vocabulary is test-only.

The prior singleton7, crop37/changed-membership22, independent-product10, Tier-0, empty/optional,
required-prerequisite, source/member/result mutation, cancellation and rollback cases remain
regressions. New focused tests cover fresh and chained attribution counter updates, foreign
mutations, native additive update payload preservation, stale targets and atomic rollback.
Exact ordinary Maven commands, totals, unsuccessful diagnostic probes, independent review and
replay hashes are recorded in the external native-root evidence and consolidated handoff.
