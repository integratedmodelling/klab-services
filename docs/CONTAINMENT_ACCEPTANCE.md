# Observational containment: bounded Tier-0 acceptance

Observational containment permits a request in an observed container. It does not
assert spatial enclosure, physical parthood, coverage, member existence or a new
native bearer. For example, `Stream contained into Region` normalizes to the
authored Region-to-Stream contract; a successful empty collective remains legal.

An independent precomputed `StreambedGradient` model may satisfy a request in a
Region under that contract. StreambedGradient remains a Ratio whose native bearer
is Stream. A successful Tier-0 strategy does not first discover Streams or bind a
Tier-1 recursive candidate. The same request in an undeclared or unrelated
container remains inadmissible; ordinary native requests remain admissible.

`ContainedTierZeroAcceptanceTest` joins actual worldview parsing and adaptation,
private OWL compilation, contextual admission, strategy matching, registered
interface transport, Resolver tier ordering and Dataflow construction. The
catalog query and Runtime contextualizer-admission service are test doubles. The
fixture uses a precomputed constant Ratio with no angular unit; it does not run a
live stack, execute the resulting dataflow or establish a deployed model catalog.
Ratio specialization is checked through the actual OWL subsumption relation.
An authored `quantity` head currently retains broad quantity enum flags; those
flags alone do not expose every more specific inherited OWL class such as Ratio.
This fixture neither changes that representation nor substitutes the flags for
the semantic subsumption proof.
The expensive later candidate is instrumented to fail if its binding or operations
are touched before complete Tier-0 fulfillment.

The isolated worldview candidate adds only Stream's observational containment in
earth:Region. It adds neither a RiverBasin definition nor blanket containment for
every Location subtype. Production adoption is a separate reviewed action.
Stream is placed last in Waterway's nested child list because a comma after the
`contained into` clause separates containment targets in the current grammar.
This mechanical reorder preserves all three child names and their parent.

## Still staged

The original StreambedGradient model depending on Elevation and Slope is not
accepted by this slice. Containment does not itself bridge those dependencies to
Stream: they still need a typed Region-field-to-Stream sampling route. Changing
the output unit alone also does not establish a dimensionally valid formula.
StreambedGradient is unitless; `degree_angle` is wrong. General canonical-unit
validation and geometry-dependent distribution remain separate implementation
work; this test must not be read as proving a new unit validator.

Height-of-Tree discovery, per-Tree resolution and regional redistribution likewise
remain future work. Native ownership, actual member binding, geometry/support,
quality-specific redistribution, gaps/overlaps and provenance need explicit
contracts. Tree need not declare Region containment merely to be instantiated by
an appropriate geometry-bound strategy. No-data never supplies zero or absence.
