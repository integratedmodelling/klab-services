# Selected-model classifier continuation: bounded singleton candidate

Ordinary `Runtime.submit` now has an internal selected-model continuation before eager
compilation. Resolver freezes the exact saved dependency occurrence and plans its required
classifier and native member producer through ordinary strategy/model selection. A typed
`ClassifierDependencyPlan` and `DEFERRED` Dataflow carry the obligation across service transport.
No classifier is dispatched while candidates are merely ranked. A successful precomputed route
with no obligation bypasses discovery and classification.

## Implemented boundary

This increment supports INIT, one classifier-expanded dependency with one abstract predicate
occurrence on the explicit named native inherent bearer, one already observed current-context
member, and at most one executable concrete result. Unsupported occurrence positions, nested
producer obligations and multiple results fail explicitly. They are not silently truncated.
The original classifier prerequisite remains required; generated dependencies retain the existing
expansion contract's optionality. Successful empty/optional NO_MODEL omits an input and fabricates
no value. UNKNOWN, producer failure and cancellation cannot become successful empty.

Runtime executes the actual producer through compile/registerExecutors/scheduler, requires its
attempt-owned INSTANTIATED/SUCCESS exact-support evidence, captures the coherent native cohort
plus attempt overlay, then invokes/reuses the planned classifier through the existing executor.
Typed redeclaration, canonical concept eligibility and the exact current context's authoritative
native-bearer proof precede concrete dependency resolution. Transaction read-view proxies are
canonicalized by their exact frozen semantic URN at the guarded accepted revision. Observable
modifiers such as `optional` are not used as concept URNs.

The concrete actuator is attached under the original scalar alias; duplicate/reserved aliases
are rejected. The parent executes once after its dependency. Root and child transport copies bind
to the transaction-owned observation with the same identity, meaning, native parent and support,
so execution/storage and committed graph identity remain aligned.

## Tier-0 priority and partial support

Resolution first exhausts rank-0 alternatives with automatic classifier obligations disabled,
including nested ordinary dependencies and explicit operation planning. Only after precomputed
alternatives fail may the request plan its classifier continuation. This also applies when a
classifier-dependent model sorts before a precomputed model or an earlier strategy needs classifiers.
The inherited planning budget prevents a nested dependency from restarting recursive work during
that first pass. Existing explicit rank-0 classification requests retain their normal route.

This increment accepts one whole-support parent result. It rejects combining accepted partial
precomputed output with a deferred classifier parent; composition and coverage policy remain outside
this verified boundary. The guard checks accepted output ancestors dynamically, excluding model
nodes whose initial full coverage describes dependency requirements rather than produced output.

## Request-local guards

The continuation binds source version/content, occurrence, support, native context identity,
accepted Reasoner identity/revision, complete classifier outcomes and the live root attempt.
Remote source/generation rechecks run outside native commit locks. Native membership/result read
sets validate on the same root-commit transaction, including reused outcomes without a new
attribution write. This does not claim an atomic remote source/worldview lease through publication,
long-lived reuse, persistent invalidation or UNKNOWN retry policy.

Compilation legitimately adds dependency children under the existing native context. A root-shared
per-observation journal records only framework HAS_CHILD count increments. Snapshot guards project
only those exact post-capture deltas through the otherwise unchanged raw/projected payload;
foreign count edits, semantics, geometry, metadata and producer witnesses remain guarded. Rollback
subtracts only this attempt's count increments. The source-plan presentation exception applies only
to typed MetadataImpl's derived suggested-name field, never an identically named computation
parameter. Planning and request continuation both reject recursive obligations without progress.
